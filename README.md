# 换版台 · 食品包装换版排期

面向采购和生产计划人员的本地测算工具。导入已确认需要换版的产品库存和生产排期，即可查看每款产品预计剩余多少旧包材、对应金额，以及新包材最迟应在哪天下单。

## 打开与使用

1. 下载并解压整个项目，用最新版 Chrome、Edge、Firefox 或 Safari 打开 `dist/index.html`。页面和 Excel 处理库均随项目提供，计算可离线完成。
2. 用内置示例试算，或下载 Excel 模板，填写“包材库存”和“生产排期”两个工作表。同一产品在两张表中使用相同编号，带前导零的编号建议设置为文本格式。
3. 导入填写好的工作簿，核对换版截止日，查看每款产品的测算结果。排产或采购交期变化后可以重新试算，并将结果导出为 Excel。

| 工作表 | 必填列 |
| --- | --- |
| 包材库存 | 产品编号、产品名称、旧包材库存、单价(元)、印刷交期(天) |
| 生产排期 | 产品编号、生产日期、包材用量 |

库存和用量使用相同的包材计量单位，每个产品的旧包材独立核算。排期填写库存盘点之后待执行的批次。一批生产若需要多个包装件，可先换算为包材用量，同一编号下可填写多批。可导入最多 2,000 款产品、50,000 条排产。请保留原工作簿以便备份。

## 计算口径

- **换版截止日**是开始强制使用新版的第一天。系统按生产日期从早到晚优先使用旧包材。截止日前某批次的旧包材不足时，该批余量计入新版需求。截止日当天及以后各批次全部使用新版。
- **预计余量**按已录入排产计算。该数量乘以旧包材单价得到预计积压金额，每款四舍五入到分。损耗、调拨或已确认的额外用量可以先计入输入数据。
- **首次新版需求日**是排期里第一次用到新版包材的生产日期。同一产品同日有多批时，新版需求量会合计。**最迟下单日**等于该生产日期减去印刷交期，交期按自然日计算。需要留出运输、验收和节假日时间时，请把这些时间计入交期。
- **尚无新版需求日**表示当前排期还没有用到新版的批次。即使旧库存刚好用完，也需要录入后续生产批次，才能算出新包材的最迟下单日。

例如，燕麦饼干有 30,000 个旧袋，单价 0.35 元。截止日前两次排产分别耗用 12,000 个和 10,000 个，预计剩余 8,000 个，价值 2,800 元。若首批使用新袋的排产在 2027 年 3 月 18 日，交期为 21 天，最迟应在 2 月 25 日下单。

默认截止日为 2027 年 3 月 16 日，对应 GB 28050-2025《预包装食品营养标签通则》的实施日期。实施前生产的食品可在保质期内继续销售。具体产品是否需要换版，请依据适用标准确认；也可将截止日改为企业自行确定的日期。[国家卫生健康委标准问答](https://www.nhc.gov.cn/sps/c100087/202509/470fa4ff5de14dd38619223cce9da4e7.shtml) · [海融食品分批换版声明](https://www.hiroad.sh.cn/news/details.htm?id=3095)

## 开发与许可

项目使用原生 HTML、CSS 和 JavaScript。使用 Node.js 20 或更高版本，在项目根目录运行 `node --test test/*.test.cjs` 可执行自动化测试。部署时可将 `dist/` 整个目录托管为静态网站。
